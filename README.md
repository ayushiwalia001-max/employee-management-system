# Employee Management System

A Python and MySQL based Employee Management System developed as part of internship project.

## Features
- Add Employee
- View All Employees
- Update Employee Details
- Delete Employee
- Search Employee

## Technologies Used
- Python 3.x
- MySQL
- MySQL Connector (Python)

## How to Run
1. Clone the repository
   git clone https://github.com/ayushiwalia001-max/employee-management-system.git

2. Install dependencies
   pip install -r requirements.txt

3. Import the database
   - Open MySQL
   - Import `employee_mng.sql` file

4. Run the project
   python main.py
